Build Images

📝 Dockerfile Examples

Node.js App

FROM node:20-alpine WORKDIR /app COPY package*.json ./ RUN npm install COPY . . EXPOSE 3000 CMD ["node", "index.js"]

Python App

FROM python:3.12-slim WORKDIR /app COPY requirements.txt . RUN pip install --no-cache-dir -r requirements.txt COPY . . EXPOSE 5000 CMD ["python", "app.py"]

Multi-Stage Build

FROM node:20-alpine AS builder WORKDIR /app COPY . . RUN npm install && npm run build FROM nginx:alpine COPY --from=builder /app/dist /usr/share/nginx/html EXPOSE 80 CMD ["nginx", "-g", "daemon off;"]

Key Dockerfile Instructions

InstructionPurpose
FROMBase image
WORKDIRSet working directory
COPYCopy files from host
ADDCopy + extract URLs/tarballs
RUNExecute at build time
CMDDefault command at runtime

EXPOSEDocument port

🧹 Cleanup Commands

docker container prune
docker image prune
docker image prune -a
docker volume prune
docker network prune
docker system prune
docker system prune -a
docker system prune -a --volumes
docker stop $(docker ps -aq)

⚠️ Warning: docker system prune -a --volumes removes ALL unused images, containers, networks, AND volumes. Data will be lost permanently.

🔧 Troubleshooting Commands

1. Container Won't Start

docker logs container_name
docker logs --tail 100 container_name
docker inspect container_name | grep -i error
docker events
docker run -it image_name sh

2. Port Already in Use

docker ps --format '{{.Names}} {{.Ports}}'
netstat -tulpn | grep 8080
lsof -i :8080
docker run -p 8081:80 nginx

3. Out of Disk Space

docker system df
docker system df -v
docker system prune -a
docker volume prune
du -sh /var/lib/docker

4. Container Exits Immediately

docker logs container_name
docker inspect container_name --format '{{.State.ExitCode}}'
docker run -it --entrypoint sh image_name

5. Network Issues

docker network inspect bridge
docker exec -it container_name ping google.com
docker exec -it container_name nslookup other_container
docker exec -it container_name cat /etc/hosts
docker exec -it container_name ip addr

6. Permission Denied

sudo usermod -aG docker $USER
newgrp docker
sudo chown $USER /var/run/docker.sock

7. Image Build Failures

docker build --no-cache -t myapp .
docker build --progress=plain -t myapp .
docker build -t myapp . 2>&1 | tee build.log

8. Performance / Resource Issues

docker stats
docker stats --no-stream
docker inspect container_name | grep -i memory
docker update --memory 512m --cpus 1.0 container_name

9. Docker Daemon Issues

sudo systemctl status docker
sudo systemctl restart docker
sudo journalctl -u docker.service -n 100
sudo dockerd --debug

10. Container Health Check

docker inspect --format='{{.State.Health.Status}}' container_name
docker inspect --format='{{json .State.Health}}' container_name | jq

11. Dive into Filesystem

docker exec -it container_name sh
docker diff container_name
docker export container_name > container.tar

12. Kernel / Runtime Diagnostics

docker info | grep -i "runtime\|kernel\|storage"
dmesg | grep -i docker
docker run --privileged -it alpine sh

🚀 Practice Application Walkthrough

Follow these steps to build, run, and troubleshoot a full practice app.

Step 1: Create Project Files

index.html

<!DOCTYPE html> <html> <body> <h1>Hello from Docker!</h1> </body> </html>

Dockerfile

FROM nginx:alpine COPY index.html /usr/share/nginx/html/ EXPOSE 80

docker-compose.yml

version: '3.8' services: web: build: . ports: - "8080:80"

Step 2: Build & Run

docker build -t hello-docker .
docker run -d -p 8080:80 --name hello hello-docker
curl http://localhost:8080

Step 3: Practice Troubleshooting

docker logs hello
docker exec -it hello sh
docker inspect hello
docker stats hello

Step 4: Clean Up

docker stop hello && docker rm hello
docker rmi hello-docker
